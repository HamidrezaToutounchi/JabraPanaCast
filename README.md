# Jabra PanaCast Türkiye - 180° Panoramik 4K Video Çözümleri

Jabra PanaCast akıllı video konferans kameraları ve video barları için geliştirilmiş özel web portalı.

## 🚀 Özellikler

- **180° Görüş Açısı (FOV) Simülatörü:** 120° standart kameralar ile 180° panoramik Jabra PanaCast arasındaki kör nokta farkını canlı gösteren interaktif karşılaştırıcı.
- **Yapay Zekâ Mimarisi:** Dynamic Composition, Virtual Director ve Akıllı Kişi Sayımı gibi yapay zekâ yeteneklerini tanıtan interaktif vitrin.
- **Detaylı Ürün Kataloğu & Sayfaları:** PanaCast 50, PanaCast 50 VBS, PanaCast 50 Room System, PanaCast 20 ve Aksesuarlar.
- **Teklif & Demo Masası:** Kurumsal test talebi ve proje fiyatı toplama formu.
- **Resmi Jabra GN Logosu:** Orijinal Jabra kurumsal kimliği ve aydınlık (light) tasarım dili.

## 🛠️ Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın (Port 3001)
npm run dev

# Üretim derlemesi oluşturun
npm run build
npm run start
```
